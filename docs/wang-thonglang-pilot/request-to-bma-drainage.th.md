# ร่างหนังสือ — ยังไม่ได้ส่ง

**เรียน** ผู้อำนวยการสำนักการระบายน้ำ กรุงเทพมหานคร

**เรื่อง** ขอความอนุเคราะห์ข้อมูลระบบระบายน้ำ เขตวังทองหลาง เพื่อทดลองแบบจำลองน้ำท่วมแบบเปิด

ผมกำลังพัฒนาแผนที่สามมิติของกรุงเทพฯ ที่แสดงสถานการณ์น้ำแบบเรียลไทม์ (atlas.nonarkara.org) โดยใช้ข้อมูลสาธารณะ ได้แก่ ระดับน้ำจากสถานีวัดของสำนักการระบายน้ำ ข้อมูลจาก สสน. และรายงานน้ำท่วมจากประชาชนผ่าน Traffy Fondue ขณะนี้ระบบแสดงได้ว่าคลองใดน้ำสูงใกล้ตลิ่ง แต่ยังคำนวณไม่ได้ว่าน้ำจะระบายออกจากถนนได้เร็วเพียงใด เพราะยังไม่มีข้อมูลท่อและเครื่องสูบน้ำ

ผมจึงขออนุญาตทดลองกับเขตวังทองหลางเพียงเขตเดียว ซึ่งสำนักฯ เคยทำแบบจำลองร่วมกับ Mott MacDonald มาแล้ว และขอความอนุเคราะห์ข้อมูลดังนี้

1. โครงข่ายท่อระบายน้ำและบ่อพัก: ขนาดท่อ ระดับท้องท่อ และความลาด
2. สถานีสูบน้ำทั้ง 10 แห่งในเขต: กำลังสูบ (ลบ.ม./วินาที) ระดับน้ำที่เริ่มและหยุดสูบ และบันทึกการเดินเครื่องช่วงวันที่ 25–28 กันยายน 2569
3. ประตูระบายน้ำ 2 แห่ง: ขนาดบาน ระดับธรณี และบันทึกการเปิดปิดช่วงเดียวกัน
4. รูปตัดและระดับท้องคลองสายหลักในเขต (ถ้ามี)
5. ข้อมูลระดับพื้นดินละเอียด (LiDAR) ของเขต (ถ้ามี)

ผมจะใช้ข้อมูลเฉพาะในการทดลองนี้ จะไม่เผยแพร่ข้อมูลดิบโดยไม่ได้รับอนุญาต และจะส่งแบบจำลอง ซอร์สโค้ด และผลการเปรียบเทียบกับสถานีวัดระดับน้ำทั้ง 5 แห่งในเขตกลับให้สำนักฯ ทั้งหมด รวมถึงค่าความคลาดเคลื่อน ไม่ใช่เพียงภาพผลลัพธ์

หากสะดวก ผมยินดีเข้าพบเพื่อนำเสนอระบบและรับฟังข้อแนะนำ
