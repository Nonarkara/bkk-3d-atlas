What ships next from one laptop

Built by a Bangkokian born in 1981 — more than 30 years inside this city. Everything below is sized for a single developer machine: static GeoJSON, free APIs, Cloudflare Workers + R2. No cluster. No consulting fee. My city, not theirs.

Research paper 432,077 buildings, 1 system, 0 politicians who care →

Shipped on this atlas

  1. Multi-layer city stack. Buildings + rail + traffic under translucent rain and AQI. Presets: City · City+rain · City+AQI · Full pulse. Overlay strength slider keeps the silhouette readable.
  2. Inspect + land-price API. Click a building → OSM type/height + nearest Treasury zone. /api/land-price with client-side fallback when the Worker is unreachable.
  3. Honest traffic. Toggle shows live vs sample · mock levels so the map never pretends a static GeoJSON is a live feed.

Next — still one laptop

  1. Flood Resilience Sandbox. Reuse terrain DEM + rain radar + building heights. Drop a static 2011 / 1-in-100 flood extent GeoJSON, opacity slider, count buildings inside the envelope. No hydrodynamic model — envelope × intersect is enough for a civic demo.
  2. Property Tax Verifier (ภาษีที่ดิน) v2. Deed-number or parcel-id lookup over Treasury zones. Compare assessed ฿/sq.wah against a typed tax bill. Surfaces the gap between assessment and collection.
  3. BTS/MRT isochrones. 5 / 10 / 15-minute walksheds from every rail station using the rail GeoJSON we already ship. Tippecanoe → PMTiles, same R2 path as buildings.
  4. Heat + khlong cooling. Open-Meteo temperature grid overlaid on the khlong network — show which canals sit under the hottest blocks. Same AQI fetch pattern, new variable.
  5. Insurance risk score (lite). GET /api/risk?lng=&lat= → land price × nearest AQI cell × rain intensity × building height. One Worker route, no GPU.
  6. Night lights / blackout view. Toggle satellite saturation + building emissive paint for a “city after dark” mode. Pure client paint — zero new data.
  7. Offline atlas pack. scripts/pack-offline.sh: pin MapLibre + pmtiles + sample traffic + land-price + areas into a folder you can open from a USB stick when the fibre dies. Laptop-native by design.

Horizon — still possible, heavier lift

  1. BKKx Digital Twin — handover to BMA. Open-source, no lock-in, no ฿5.4M consulting fee. The system proves the technical path; the political handover is the deliverable.
  2. Property-tech API (full). 432K buildings + heights + cadastral polygons as JSON / GeoJSON / MVT. Needs Royal Thai Survey boundary files — the hard part is institutional, not code.
  3. Tourist AR — point, learn. Rattanakosin detail PMTiles + temple / museum tags as a PWA. No app store.
  4. Urban Planning Decision Support. Drag a BTS station, watch land-price heat move. Drag a flood barrier, watch AQI cells shift. Sandbox for decisions BMA should be making.
  5. BMA Command Center. Live ops dashboard of every layer on one screen. Same Worker, denser chrome, training for operators.
  6. Open Data Marketplace. Anonymized patterns from PMTiles + tourism + land- price changes. The anonymity promise is real because the tiles never tracked people.
  7. Bangkok in the Metaverse. 1:1 twin for virtual plots — only after the civic layers above are boringly reliable.

BMA — the Bangkok Metropolitan Administration — has been "planning a smart city" since 2016. Ten years. Ten digital strategies. Zero public APIs, zero open data, zero digital twin. Meanwhile the buildings are getting taller, the floods are getting deeper, and the only dashboard the public gets is a 1990s PDF map. We built the whole thing on a one-laptop budget. The system is not the hard part — keeping every layer honest and stackable is.
